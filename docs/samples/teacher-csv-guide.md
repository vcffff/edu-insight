# Пример CSV для учителя

Оба файла содержат **вымышленные** данные: 10 учеников 7А класса, два предмета и четыре темы. Имена учеников не нужны — используются одинаковые условные `student_id` в обоих файлах.

1. Загрузите [teacher-assessments.csv](teacher-assessments.csv) на экране «Источники данных». Каждая строка — результат одного ученика по одной теме. В этом примере оценка `score` равна числу верных ответов из четырёх заданий (`max_score=4`).
2. Выберите только что загруженный датасет и загрузите [teacher-item-responses.csv](teacher-item-responses.csv) в блоке «Ответы по заданиям». Каждая строка — ответ ученика на одно задание: `1` — верно, `0` — неверно. `skill` обозначает проверяемый навык, `item_id` — код задания.
3. Выберите предмет в аналитике тем и в рекомендациях. Результаты будут рассчитаны из строк этого предмета. Диагностика навыков появится в деталях темы.

Для собственных данных замените условные ID, названия предметов, тем, учебников, даты и результаты. В основном CSV обязательны `student_id`, `topic`, `textbook`, `score`, `max_score`; `subject`, `assessment_date`, `class_id`, `grade` необязательны. Для анализа по предметам заполняйте `subject` в каждой строке. Во втором CSV нужны `student_id`, `topic`, `skill`, `item_id`, `is_correct`; `subject` нужен, когда одинаковая тема встречается у ученика в нескольких предметах.

Второй файл необязателен. Если его нет, сайт покажет баллы по темам, но не сможет назвать конкретные ошибки или посчитать правильные и неправильные ответы.
